# 🏭 Takt Studio
**Diseña, simula y optimiza tu línea de producción antes de tocarla.**
Takt Studio es una herramienta web de simulación y análisis de líneas de producción industrializada, orientada inicialmente a módulos de baño prefabricados (Monobath). Permite modelar estaciones, identificar cuellos de botella, calcular KPIs lean y comparar escenarios what-if.

## Stack
- Next.js 14 (App Router) + TypeScript
- Tailwind CSS + shadcn/ui
- Recharts para visualizaciones
- Zustand para estado
- Vercel para despliegue

## Desarrollo local
npm install
npm run dev

## Tests
npm test
